# Circular Singly Linked List in Java

## Introduction

A Circular Singly Linked List is a linear data structure
in which the last node points back to the first node (head).

Unlike a normal singly linked list, it does not end with null.

## Features

- Insert at the beginning
- Insert at the end
- Insert at a specific index
- Insert after a specific index
- Delete the first node
- Delete the last node
- Delete at a specific index
- Delete after a specific index
- Search by value
- Get a node by index
- Display the list
- Track the list size

## Structure

head -> 10 -> 20 -> 30 -> 40
  ^                         |
  |_________________________|

## Time Complexity

| Operation | Time Complexity |
|-----------|-----------------|
| insertFirst() | O(1) |
| insertLast() | O(1) |
| insert() | O(n) |
| insertAfter() | O(n) |
| deleteFirst() | O(1) |
| deleteLast() | O(n) |
| deleteAt() | O(n) |
| deleteAfter() | O(n) |
| get() | O(n) |
| find() | O(n) |
| display() | O(n) |
